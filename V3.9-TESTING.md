## What's Inside (Real Algorithms):

### 1. Blink Detection ✅
- Monitors brightness changes in eye regions
- Threshold: Brightness delta > 15 = blink
- Tracks blinks per minute
- Debounced (100ms minimum between blinks)

### 2. Smile Detection ✅
- Analyzes mouth region brightness
- Teeth showing = brighter region
- Threshold: Brightness > 140 = smile
- Counts smiles, not random!

### 3. Lean Detection ✅
- Tracks face size changes over time
- Larger face = leaning forward
- Smaller face = leaning backward
- Smoothed with 90/10 moving average

### 4. Gaze Tracking ✅
- Monitors face position in frame
- Center = looking at screen
- Off-center = gaze wandering
- Updates attention score

### Smile Detection:

### Lean Detection:
